OVR Overlay Translator captures on-screen text and displays a translated overlay inside SteamVR, supporting dozens of language pairs through cloud translation APIs.

Whether you're a newcomer or a veteran, OVR Overlay Translator provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
